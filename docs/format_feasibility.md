# 格式支持可行性评估（MOBI/AZW3/FB2/CBR/RAR）

结论：本轮**不内置**这些格式，建议由宿主应用在导入阶段转换为已支持格式。

| 格式 | 现状 | 可行性 | 建议 |
| --- | --- | --- | --- |
| EPUB / TXT / MD / HTML / PDF / CBZ | 已支持 | - | - |
| FB2 | 未支持 | 高。本质是 XML，可用 `xml` 包解析为 `NovelChapter` | 后续可作为纯 Dart 解析器加入，工作量小 |
| MOBI / AZW3 (KF8) | 未支持 | 中低。需实现 PalmDOC/LZ77 解压、EXTH、KF8 资源索引；多数文件带 DRM | 宿主用 Calibre 等转换为 EPUB |
| CBR / RAR | 未支持 | 低。RAR 压缩算法为专有，Dart 无成熟纯实现，需要原生库（unrar），增加包体积和各平台构建复杂度 | 宿主转换为 CBZ，或自行解压后用页面字节/URL 传入 |

## 备注
- 带 DRM 的文件无论格式均不在支持范围内。
- 若后续需要 FB2，建议新增独立的 FB2 解析器，输出现有章节模型，不改动试读逻辑。
